# 隐私与数据

以下描述项目代码提供的行为；自行部署的运营者应补充自己的主体、联系方式、服务器位置和保留期限。

| 选项 | 默认 | 内容 |
|---|---|---|
| 使用统计 | 开启，可关闭 | 随机安装 ID、机型、系统与应用版本、启动/模拟次数及时间 |
| 崩溃日志 | 开启，可关闭 | 经脱敏处理的堆栈与日志；关闭不影响手动确认的反馈 |
| 真实位置 | 开启，可关闭 | 最近一次真实经纬度、精度与时间，仅前台且未模拟时尝试 |

引导页展示上述选项，用户可取消选中；设置页可随时修改。地图定位授权与上报开关是不同设置。随机安装标识可关联设备记录和位置，不等同于不可识别的匿名信息。

关闭统计或位置时请求删除统计与位置快照，然后仅按仍开启的选项上报。关闭崩溃上报时清理本地待传崩溃文件，并请求删除带本安装凭据的服务端日志。“全部关闭并删除”同时关闭三个选项。断网时请求保留到下次前台联网重试，界面保存成功不代表服务器已经删除成功。

服务器统计表只保存最近一次位置快照，不保存轨迹历史；数据库备份可能保留旧快照，由运营者按保留周期清理。未绑定安装凭据的旧版本日志需要管理员处理。卸载会丢失本机随机安装凭据，可能需要人工核验删除请求。

位置坐标不写入本地遥测文件或日志，模拟路线则按用户操作保存在本地。地图功能依赖百度地图 SDK。运营者应独立核实第三方 SDK 的数据处理、部署地域、必要告知与适用规则；本说明不能替代具体服务的隐私政策。
